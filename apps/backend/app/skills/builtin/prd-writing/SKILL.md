# PRD writing

Write for the person who asked, not for engineers. Use these sections, each short:

1. **What it is**: one sentence.
2. **Who it is for** and the main thing they do.
3. **Must-haves**: a bullet per feature, in the user's words.
4. **Out of scope**: what you are deliberately not building.
5. **Assumptions**: every guess you made, so the user can correct it.

No jargon, no implementation detail, no feature the user did not ask for. If the idea is large,
say what the first version contains.
