# Codebase exploration

- Start with the repo map and `list_files`; read the README, the run contract and the entry
  points before anything else.
- Use `search_code` for names you expect, then read only the files that matter.
- Follow the data: where it comes from, how it is changed, where it is stored and shown.
- Report with paths and line references, not summaries from memory; say clearly what you did not look at.
- Do not change files; your output is an answer for someone else to act on.
